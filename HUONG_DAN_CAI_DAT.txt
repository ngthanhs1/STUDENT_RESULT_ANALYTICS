1. CẤU HÌNH CƠ SỞ DỮ LIỆU SQL SERVER
================================================================================
- Instance SQL Server: .\SQLEXPRESS (hoặc tên instance của máy bạn).
- Tên Cơ sở dữ liệu: StudentResultAnalyticsDB
- Xác thực: Windows Authentication (Integrated Security=True).
- Script CSDL: File `Tong_hop_SQL_StudentResultAnalyticsDB_01-11-2026.txt` chứa đủ:
  + 7 bảng dữ liệu chuẩn hóa: Lop, SinhVien, MonHoc, HocKy, KetQua, TaiKhoan, LichSuNhapDuLieu.
  + 4 View phân tích:
    * vw_SinhVienThieuDiem
    * vw_DiemTrungBinhHocKy
    * vw_ThongKeDatTruot
    * vw_PhanLoaiHocLuc
  + Ràng buộc toàn vẹn: Khóa ngoại, CHECK(0 <= Diem <= 10), UNIQUE(MaSV, MaMonHoc, MaHocKy).
  + Cột tính toán tự động: DiemTongKet = ROUND(DiemChuyenCan*0.1 + DiemGiuaKy*0.3 + DiemCuoiKy*0.6, 2) PERSISTED.

3. CẤU TRÚC 5 PHÂN HỆ NGHIỆP VỤ CHUẨN ĐẠI HỌC (ĐÃ TÁI CẤU TRÚC)
================================================================================
1. TỔNG QUAN:

2. QUẢN LÝ ĐÀO TẠO:
